## 📂 Проекты

### 🔹 [Manual Testing — SauceDemo](https://github.com/oklatri/manual-testing-saucedemo)
Ручное тестирование учебного интернет-магазина.
- 18 тест-кейсов, 12 баг-репортов, чек-листы, Test Plan
- Test Design: EP, BVA, Decision Table, State Transition, Error Guessing, Decomposition
- Traceability matrix (ручные TC ↔ автотесты)
- Test Execution Report: 15 Passed / 3 Failed / 0 Blocked, 7 Major + 5 Minor дефектов

### 🔹 [UI Automation — Playwright](https://github.com/oklatri/ui-automation-playwright)
UI-автотесты для SauceDemo.
- 8 автотестов (логин + корзина)
- Page Object Model, JavaScript, Node.js
- CI/CD через GitHub Actions
- HTML-отчёт в артефактах сборки

### 🔹 [API Testing — JSONPlaceholder](https://github.com/oklatri/api-testing-jsonplaceholder)
API-тестирование публичного REST API.
- 8 тест-кейсов, 3 баг-репорта
- Коллекция Postman с 13 автотестами
- Проверка статус-кодов, схем, граничных значений

### 🔹 [SQL Portfolio — MySQL](https://github.com/oklatri/sql-portfolio)
Практика SQL-запросов.
- 20 запросов: SELECT, JOIN, GROUP BY, агрегация
- Data validation, проверка целостности
